Upload your league JSON

Choose the JSON export containing every team and its players. This replaces the current draftboard and starts a fresh trade session.

{
  "league": "My League",
  "format": {"QB": 1, "RB": 2, "WR": 2, "TE": 1, "FLEX": 1},
  "teams": [{
    "team_name": "My Team",
    "owner": "Your Name",
    "roster": [{"name": "Player Name", "position": "RB", "team": "BUF"}]
  }]
}

The file should be a top-level array of team objects, or an object with a format header plus teams (e.g. {"format": {"QB": 1, "RB": 2, "WR": 2, "TE": 1, "FLEX": 2}, "teams": [...]}). Each roster entry needs name, position, and the NFL team abbreviation. Without a format header the lab assumes 1 FLEX.
